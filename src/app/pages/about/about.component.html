A propos du projet

Application meteo realisee dans le cadre du cursus a l'IPSSI.

Presentation

Weather App est une application web developpee avec le framework Angular permettant de rechercher des villes et de visualiser la meteo en temps reel ainsi que les previsions sur 5 jours grace aux donnees de l'API OpenWeather.

Technologies utilisees

  • Angular : Framework front-end moderne base sur des composants standalone.
  • TypeScript : Typage statique robuste et maintenance facilitee.
  • Angular Router : Gestion de la navigation et des routes dynamiques avec parametres.
  • Angular HttpClient : Requetes HTTP asynchrones avec Observables RxJS.
  • OpenWeather API : Fournisseur de donnees meteorologiques mondiales.
